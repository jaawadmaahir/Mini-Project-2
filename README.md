# Mini Project 2: Responsive Portfolio (JM.DEV)

Personal portfolio of **Mohammad Jawad Mahir** (BSc in CSE, IIUC), built for CSE-2340 Software Development I.

**Live site:** https://jaawadmaahir.github.io/Mini-Project-2/

## Built with
- HTML5 (semantic elements)
- Tailwind CSS (CDN)
- Vanilla JavaScript

## Features
- Sticky navbar with scroll highlighting and a mobile menu
- Home, About, Skills, Projects, Journey, Resume and Contact sections
- Dark / light theme toggle (remembers your choice)
- Hover effects, intro popup, working contact form (opens your email app)
- Fully responsive for mobile and desktop
